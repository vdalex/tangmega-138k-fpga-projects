LiteX SoC on the hard AE350 with 1 GiB of DDR3 through Gowin's DDR3 Memory
Interface IP. Built with the Education edition; BIOS cross-built on aarch64.

    --with-gowin-ddr3
    --gowin-ddr3-netlist .../ddr3_memory_interface/ddr3_memory_interface.v
    --gowin-pll-init     .../src/pll_init.v


--================ SoC =================--
CPU:            Gowin AE350 @ 800MHz
BUS:            wishbone 32-bit data/32-bit addr
CSR:            32-bit data big ordering
ROM:            128.0KiB
SRAM:           8.0KiB
MAIN RAM:       1.0GiB

The read figure is the upconverter's line cache being defeated by
AHB2Wishbone never emitting a burst CTI, not the memory - see the README.

Control experiment, to separate the board from the integration: Sipeed's
unmodified ddr_memory_test_uart, rebuilt from their own .gprj file list and
flashed to the same board. Its UART is held in reset unless
init_calib_complete && !err, so the message is itself the result.
